# PyHydroGeophysiX_Carl Examples

This directory contains example notebooks and scripts demonstrating the usage of PyHydroGeophysiX_Carl for coupled hydrogeophysical modeling.

## Notebooks

- `01_data_ingestion_intro.ipynb` - Introduction to data ingestion pipeline
- `02_coupled_2d_modeling.ipynb` - Coupled 2D modeling with synthetic data
- `03_coupled_2d_real_data.ipynb` - Coupled 2D modeling with real field data
- `04_database_viewer.ipynb` - Exploring processed data

## Scripts

- `build_database.py` - Build processed database from raw data
- `generate_modeling_notebook.py` - Generate modeling notebooks programmatically

## Data

The `examples/data/` directory contains sample datasets for testing the examples. For full datasets, see the main `data/` directory.
